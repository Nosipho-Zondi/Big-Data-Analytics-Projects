# Loan Disbursement Forecasting

Time-series forecasting of loan disbursements using Power BI to predict future lending volumes and support planning.

## Project Overview
Analyzed historical loan disbursement data to identify trends, seasonality, and growth patterns. Built a forecasting model to predict future disbursements for business planning and liquidity management.

## Objective
- Analyze historical loan disbursement trends
- Identify seasonal patterns and growth rates
- Forecast future disbursement volumes

## Dataset
- **Source:** Loans Disbursed (historical records)
- **File:** Loans Disbursed.xlsx
- **Fields:** Disbursement date, loan amount, loan type/category (as applicable)
- **Period:** 2020 - 2025

## Methodology
1. **Data Cleaning:** Standardized dates, handled missing values, removed duplicates
2. **Exploratory Analysis:** Monthly/quarterly trends, moving averages, YoY growth
3. **Forecasting:** Built forecast using Power BI Forecast
4. **Visualization:** Actual vs Forecast chart
5. **Video Walkthrough:** Recorded explanation of approach and findings
